Comment démarrer

Deux façons d'utiliser ImmoScout. Les deux nécessitent une clé API Anthropic (gratuite).

1

Analyser une annonce (recommandé)

Trouvez un appartement sur LeBonCoin ou PAP.fr, copiez son URL et collez-la dans la zone "Analyser une annonce" ci-dessus. Vous obtenez immédiatement la rentabilité, le cashflow et toutes les informations.

2

Scanner automatiquement

Ajoutez vos villes et votre budget dans la barre en haut, puis cliquez sur Scanner. Claude recherche des annonces sur LeBonCoin et PAP.fr et vous propose les meilleures opportunités.

🔑

Obtenir une clé API (2 min)

1. Allez sur console.anthropic.com
2. Créez un compte gratuit
3. Cliquez "API Keys" → "Create Key"
4. Copiez la clé (sk-ant-...)
5. Collez-la dans

Pour chaque bien : rentabilité nette, cashflow mensuel, simulation de négociation, lien direct vers l'annonce exacte, téléphone de l'agence ou du propriétaire.
